# Metrik Print Agent Tray

Conector local de [Metrik POS](https://metrikpos.com) para impresoras de etiquetas SATO, desde la bandeja del sistema de Windows.

Este repositorio solo aloja los instaladores publicados (sección **Releases**). El código fuente es privado.

**Descarga e instrucciones:** <https://metrikpos.com/descargas>
